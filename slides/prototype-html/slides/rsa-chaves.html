RSA: fabricando as chaves

  1. Escolha dois primos grandes, p e q
  2. n = p · q
  3. φ(n) = (p − 1)(q − 1)
  4. Escolha e com mdc(e, φ(n)) = 1
  5. d = inverso de e módulo φ(n)

Chave pública: (n, e). Chave privada: (n, d).

Exemplo pequeno

p = 61, q = 53

n = 3233, φ(n) = 3120

e = 17, d = 2753

m = 65 → c = 65^17 mod 3233 = 2790

2790^2753 mod 3233 = 65
