Se você é da turma de C ou Java, a pegadinha mais importante é o %: em C e Java, -3 % 26 dá -3; em Python dá 23, que é o que a matemática modular precisa. ord e chr fazem o papel do cast entre char e int. A indentação substitui as chaves. Abra o Colab e mostre cada linha rodando em uma célula. Aqui é um bom momento para admitir que você também está aprendendo Python, se quiser.
