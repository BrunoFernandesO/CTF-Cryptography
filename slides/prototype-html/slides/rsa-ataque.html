Soluções dos TODO: while n % f != 0 e phi = (p - 1) * (q - 1). É o nível 3 do CTF: o aluno cola n, e e c do puzzle dele, fatora, calcula d com pow(e, -1, phi) e decifra com pow(c, d, n); a flag é FLAG{m}. Cada aluno tem n diferente. Se o tempo estiver curto, faça a fatoração como demonstração sua: gere um n com primos de 4 a 6 dígitos, mostre a divisão sucessiva e meça o tempo à medida que n cresce, para a turma sentir por que o tamanho da chave importa. Com 2048 bits (cerca de 617 dígitos), fatorar não é viável com os métodos conhecidos.
